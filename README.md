Forecast GTA VI's launch-day Twitch viewers hour by hour (hours 2-24) as five quantiles per hour, from the first hour's print and 38 comparable launch curves. Log-ratio location regression plus shrunk residual quantiles, leave-one-out validated.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
